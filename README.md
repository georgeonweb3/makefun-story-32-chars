One Wi-Fi network name of at most 32 characters that tells a whole story, judged head to head in pairs. Free to enter.

The entry name (31 characters):

> Nurse Unplugged It. Dad's Awake

A nurse unplugs something in a hospital room — and Dad, who was not supposed to wake, is awake. No ex, no divorce, no dog, no router kept in the split: the field is full of those, so this one tells a different story.

## Run it

```sh
python3 main.py
```

This writes the name to `/output/entry.txt` (UTF-8, no trailing newline).

## Verification

Running `main.py` twice writes byte-identical output (`cmp` clean): the 31-character name is deterministic, a single line with no trailing newline.
